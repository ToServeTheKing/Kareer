# Security Policy

## Supported Versions

Only the latest release gets security fixes.

## Reporting a Vulnerability

Please do not open a public issue for a security problem. Email
austin@thebennett.net with a description, the steps to reproduce it, and the
version you found it in. You will get a reply within a week, and a fix or a
plan before anything is made public.

This covers the desktop app, the `kareer` CLI and the sync server in
`server/`.
